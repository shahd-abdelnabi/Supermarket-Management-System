# Supermarket Management App

A desktop checkout application built with **C# and Windows Forms** that simulates a real supermarket shopping experience, from browsing products to printing an itemized invoice.

Developed as a project for the **Object-Oriented Programming 2** course at the Faculty of Computers and Artificial Intelligence, Sohag University.

## Features

- 8 color-coded product categories: Dairy, Vegetables, Fruits, Bakery, Drinks, Snacks, Meat & Poultry, and Cleaning
- Browse the items in each category with live prices
- Shopping cart with quantity control, add/remove items, and automatic updates
- Real-time subtotal, VAT, and total calculation
- Printable invoice with an invoice number, date, and itemized receipt

## Concepts Practiced

- Object-oriented programming: classes, properties, and encapsulation
- Collections: List, Dictionary, and BindingList
- Event-driven programming and data binding
- Building a clean, professional user interface entirely in code

## Tech Stack

- C#
- Windows Forms (.NET)
- Visual Studio

## How to Run

1. Clone or download this repository.
2. Open the `.sln` file in Visual Studio (with the ".NET desktop development" workload installed).
3. Press F5 to build and run the application.
